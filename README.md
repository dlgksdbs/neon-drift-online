# 🏎️ NEON DRIFT · 3D 네온 레이싱

모바일 웹(안드로이드 세로 390×844 기준, 가로 지원)에서 부드럽게 도는 **3D 네온 레이싱** 게임.
혼자서 AI 3명과 달리거나, **방 코드로 친구와 1:1·다인전** 실시간 대결을 할 수 있다.

- Node.js + Express + `ws`(WebSocket) + `three@0.169.0` (외부 CDN 의존 0, `public/vendor` 로컬 번들)
- 폰 트랙 `public/js/core/*` 는 순수 JS 모듈이라 **서버 검증과 클라이언트가 같은 물리/체크포인트 로직**을 쓴다.

## 실행

```bash
npm install
npm start            # PORT=3000
PORT=8080 npm start  # 포트 지정
```

- 게임: `http://localhost:3000/`
- 헬스체크: `GET /healthz` → `{"ok":true,"name":"neon-drift-online", ...}`
- 방 정보: `GET /api/info`
- 친구 초대: `/?room=ABCD` (방 코드 자동 참가), `&name=닉네임` 으로 이름 지정

## 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 조향 | 왼쪽 하단 **원형 핸들**(돌려서 조향, 좌우 반전 가능) | A/D, ←/→ |
| 가속 | 자동 가속(기본 ON) | W/↑ (자동 가속 끄면 수동) |
| 브레이크 | BRAKE | S/↓ |
| 부스터(니트로) | NITRO | Shift |
| 시점 전환 | 오른쪽 위 👁️ | C |
| 일시정지 | ⏸ | Esc |
| 조작 좌우 반전 | 메인 메뉴 · 일시정지의 `⇄ 조작 좌우 반전` | - |

**원형 핸들(3D 운전교실 스타일)**: 핸들을 손가락으로 돌리면 최대 ±135°까지 회전하고 그 각도에 비례해
차가 즉시 그 방향으로 꺾인다. 손을 떼면 핸들이 부드럽게 정면으로 돌아오고 조향도 0이 된다.
핸들은 기본으로 화면 왼쪽 하단에 있고, `⇄ 조작 좌우 반전`을 켜면 핸들과 NITRO·BRAKE 를 좌우로 맞바꿔
오른손 조향으로 달릴 수 있다. 설정은 브라우저에 저장되어 새로고침해도 유지된다.

바닥의 화살표 **부스터 패드**를 밟으면 즉시 가속한다.

**실시간 순위표**: 레이스 중 화면 왼쪽 위에 1~4위(다인전은 전원) 순위·이름·랩이 표시되고, 내 차량 행이
네온으로 강조된다. 결승선을 통과하면 결과 화면에 최종 순위·기록·베스트랩이 정리된다.

## 게임 구성

- **트랙**: 네온 하버 서킷(1,169m 폐곡선, 폭 18m, 체크포인트 8개, 3랩). 직선·완만한 커브·헤어핀(최소 반경 27m) 혼합.
- **차량 3종**: 네온 쿠페(밸런스) · 코너 GT(조향 응답↑) · 하이퍼카(최고속↑) + 네온 컬러 6색.
- **주행 모델**: 누른 방향으로 즉시 꺾이는 카트형 조향, 횡슬립 최소(미끄러지지 않음), 가속·제동·니트로·가드레일 충돌.
- **시점**: 다이나믹 3인칭(속도·부스터에 따라 FOV/거리 변화) ↔ 1인칭 후드.
- **효과**: 스파크, 배기 불꽃, 스피드 라인, 월드 네온 스카이라인/가로등/체크포인트 아치.
- **모드**: 혼자 달리기(AI 3명, 닉네임 비우면 '드라이버') / 친구랑 대결(방 코드, 대기실, 3-2-1-GO, 실시간 위치·회전·부스터 동기화, 실시간 순위·완주 결과).

## 구조

```
server.js                    Express + WebSocket 방/레이스 서버 (진행도 서버 검증)
public/index.html, css/      UI (메뉴·로비·HUD·순위표·결과)
public/js/core/              순수 로직 (서버·클라이언트 공용)
  track.js                   트랙 스플라인·체크포인트·부스터 패드
  physics.js                 카트형 조향·가속·제동·니트로·충돌 물리
  progress.js                순서 기반 체크포인트·랩·순위
  ai.js                      AI 레이싱 라인·코너 속도 계획
public/js/game/              3D (scene/trackMesh/carModel/effects/hud/wheel)
public/js/net.js             WebSocket 클라이언트
public/js/main.js            게임 루프·모드·카메라·입력
test/unit.js                 물리·체크포인트·AI 단위 테스트
test/server.js               HTTP·WebSocket 방/동기화/완주 테스트
test/mobile.js               390×844 실제 렌더 테스트(핸들·순위표·UI 겹침·멀티 동기화)
```

## 테스트

```bash
npm test             # unit + server
npm run test:mobile  # 모바일 실렌더 (스크린샷 → downloads/neon-drift-shots)
```
